A2Z DSA sheet tracker that runs your code in the browser

DiffPush is a free, browser-based cockpit for the 369-problem A2Z DSA sheet. Write a solution, run real test cases locally, and auto-commit every accepted answer to your own GitHub repository.

  • 369 problems across 16 interview topics, each with examples, constraints, and complexity targets.
  • Zero-latency execution: Python via Pyodide and JavaScript via a local Web Worker; solutions never leave your machine.
  • GitHub auto-commit: accepted code lands in your repo with a consistent folder structure.
  • Leitner spaced repetition: review weak problems on a schedule instead of re-reading everything.
  • No signup: guest progress is stored in your browser; connect GitHub or an account only when you want sync.
