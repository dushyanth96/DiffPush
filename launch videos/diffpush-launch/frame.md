# DiffPush Launch Video Frame

## Design Spec

**Brand Colors:**
- Primary: #10b981 (green accent)
- Secondary: #3b82f6 (blue accent) 
- Background: #07090e (dark navy)
- Text: #e6eaf2 (light gray)
- Subtext: #b6c2d2 (medium gray)

**Typography:**
- Headlines: Inter 700 (64-120px)
- Body: Inter 400 (28-42px)
- Code: JetBrains Mono 500 (20px+)

**Visual Style:**
- Dark theme with green accents
- Glass-morphism cards with backdrop blur
- Smooth animations and transitions
- Clean, modern aesthetic
- Tech-savvy but approachable

## Background Layer
- Radial glow in the background (accent-tinted, low opacity)
- Ghost text with theme words at 3-8% opacity
- Subtle breathing animation on decorative elements

## Motion
- 0.3-0.6s durations for most animations
- Vary eases and combine transforms on entrances
- Overlap entries with different timing
- Ambient motion on background elements

## Composition Density
- 4-6 visual roles per scene
- Hero section with logo, title, subtitle
- Feature cards with glass-morphism effect
- Demo elements showing code execution
- CTA with clear call-to-action button
