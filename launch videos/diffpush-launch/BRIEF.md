## Intent

Create a 30-second launch video for DiffPush that introduces the product as a free, browser-based A2Z DSA sheet tracker. The video should highlight its key features and encourage viewers to try it out.

## Product Overview

DiffPush is a free, browser-based cockpit for the 369-problem A2Z DSA sheet. It allows users to:
- Write solutions in Python or JavaScript that run locally in the browser via WebAssembly and Web Workers
- Execute real test cases with pass/fail feedback
- Commit accepted solutions to their own GitHub repository after review
- Use Leitner spaced repetition for reviewing weak topics

## Key Features to Highlight

1. **369 Problems Across 16 Topics** - The comprehensive DSA problem set
2. **Zero-Latency Execution** - Solutions run directly in the browser
3. **GitHub Integration** - Commit accepted solutions to your own repository
4. **Spaced Repetition** - Review weak topics with intelligent scheduling

## Target Audience

Tech students preparing for coding interviews who want a free, accessible way to practice DSA problems.

End the video with a clear invitation to visit https://diffpush.pages.dev and start practicing DSA problems.
